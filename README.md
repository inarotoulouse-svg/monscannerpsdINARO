# 🔎 monscannerpsdINARO

Un outil simple et rapide en Python pour vérifier si un pseudo existe sur plus de 15 réseaux sociaux majeurs (TikTok, Instagram, Roblox, Snapchat, Spotify, etc.).

## 🚀 Installation

Pour installer l'outil, tu as juste besoin de cloner le projet et d'installer la bibliothèque requise. Ouvre ton terminal et ecrit dans l'ordre :

git clone https://github.com/inarotoulouse-svg/monscannerpsdINARO.git

cd monscannerpsdINARO

pip install requests


🎮 Comment l'utiliser?
Pour lancer le scanner, va dans le dossier et réveille le script avec Python :
python monscanner.py

Ensuite, entre simplement le pseudo que tu veux chercher et laisse la machine bosser !
